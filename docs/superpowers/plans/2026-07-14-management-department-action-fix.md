# Контекстное добавление отдела в управление: план исправления

> **Для агентных исполнителей:** обязательно использовать `superpowers:subagent-driven-development` для выполнения задачи с независимым ревью. Шаги отмечены чекбоксами.

**Цель:** В раскрытом управлении снова дать возможность открыть форму создания отдела, уже привязанного к этому управлению.

**Архитектура:** `OrganizationUnitsPanel` остаётся владельцем формы подразделения. Дерево подразделений получает локальный callback для открытия формы, а узел управления показывает действие только после раскрытия. Создание отправляет существующий `parent_id` выбранного управления; верхняя кнопка карточки продолжает создавать самостоятельный отдел.

**Технологии:** React, TypeScript, TanStack Query, Vitest, Testing Library.

## Глобальные ограничения

- Не менять API, таблицы, правила архивации, аудита или прав доступа.
- Управления остаются корнями; отдел может быть самостоятельным или дочерним только выбранного управления.
- Внешний интерфейс остаётся русскоязычным; технические коды не показываются.
- Клик по имени подразделения продолжает открывать только встроенное редактирование имени.
- Клик по свободной области управления раскрывает список; контекстное действие открывает форму и не переключает раскрытие.
