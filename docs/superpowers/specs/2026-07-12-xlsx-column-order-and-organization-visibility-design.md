# Порядок колонок и скрытие организации в XLSX

## Цель

Сделать XLSX-порядок независимым от порядка кликов пользователя: сначала идут
поля первого блока формы, затем второго и так далее; внутри блока поля идут по
их сохранённой строковой позиции. Колонка `Организация` по умолчанию не
выводится в XLSX, но пользователь может показать её при необходимости.

## Порядок полей

- Сервер, а не браузер, приводит выбранные поля к каноническому порядку
  `(позиция блока, id блока, позиция поля, id поля)`.
- Этот порядок применяется одинаково к экспорту, шаблону, метаданным и
  проверке загруженного файла. `№ п/п` остаётся первой колонкой всегда.
- Выбор полей в интерфейсе остаётся произвольным: порядок чекбоксов не
  становится отдельной пользовательской настройкой XLSX.

## Организация

- В параметрах XLSX есть отмеченный по умолчанию переключатель `Скрывать
  колонку «Организация»`. В API ему соответствует
  `include_organization_column=false`.
- Если колонка скрыта, файл содержит `№ п/п`, затем поля. В шаблоне импорта
  организация строки берётся из служебных метаданных, которые сервер повторно
  проверяет, а не из значения ячейки.
- При одной выбранной организации она автоматически становится организацией
  импорта. При нескольких выбранных организациях шаблон импорта требует явный
  выбор `Организация для импорта`; это значение записывается в его метаданные.
  Экспорт списка при этом остаётся доступен без дополнительного выбора:
  он предназначен для чтения и не выдаёт себя за готовый шаблон импорта.
  Поэтому скрытие доступно при любом числе выбранных организаций и не создаёт
  неоднозначных импортов.
- Если переключатель выключен, возвращается текущая колонка `Организация` с
  проверкой Excel-списка; организация определяется для каждой строки.
- В метаданные добавляются `include_organization_column` и
  `fixed_organization_id`. Старые файлы без этих ключей трактуются как
  содержащие колонку организации, поэтому их можно продолжать импортировать.

## Безопасность и ошибки

- `fixed_organization_id` обязана входить в выбранный и доступный пользователю
  список организаций; это проверяет сервер до формирования книги и при чтении
  метаданных.
- При скрытой колонке проверка/импорт возвращают для каждой строки подпись
  фиксированной организации. При видимой колонке сохраняется существующая
  проверка значения из ячейки.
- Формат не принимает пользовательский порядок полей и не доверяет
  идентификатору организации вне серверно проверенной конфигурации.

## Проверка

- Backend unit-тесты доказывают каноническую сортировку, отсутствие колонки и
  Excel-проверки организации в скрытом режиме, а также совместимость видимого
  режима.
- Frontend-тест доказывает, что скрытие включено по умолчанию, а при выборе
  нескольких организаций требуется явная организация импорта.
- Живая проверка подтверждает заголовки скрытого и видимого XLSX, состояние
  переключателя и отсутствие ошибок в браузере.
