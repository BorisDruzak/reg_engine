# Сегментированный ввод стажа

## Цель

Сделать редактирование значения поля типа `work_experience` понятным и
быстрым: пользователь вводит три числа в одной строке, а слова единиц времени
всегда остаются видимыми и склоняются автоматически.

## Граница изменений

Меняется только клиентский редактор значения. Контракт API, хранимое сервером
`anchor_date`, серверный расчёт стажа и отображение в документах и экспорте не
изменяются.

## Интерфейс

Редактор отображает одно визуальное поле:

```text
[ 16 ] дней [ 3 ] месяца [ 9 ] лет
```

Это три доступных числовых input-элемента в общем контейнере, с постоянными
словами единиц между ними. У каждого сегмента есть понятная метка для
скринридера: «дни», «месяцы» или «годы». Три input-элемента не переносятся на
следующую строку на обычной ширине карточки; узкий экран допускает естественный
перенос, но сохраняет порядок сегментов.

## Поведение ввода

- Каждый сегмент принимает только неотрицательное целое число.
- После заполнения дней клавиша `Пробел` переводит фокус на месяцы; после
  заполнения месяцев — на годы.
- В сегменте лет `Пробел` не меняет фокус и не изменяет значение.
- Обычные клавиши `Tab` и `Shift+Tab` сохраняют стандартную навигацию.
- Форма слов пересчитывается сразу после изменения числа: `1 день`, `2 дня`,
  `5 дней` и те же правила для месяцев и лет.
- Полное значение отправляется в существующем виде
  `{ days, months, years }` только когда все три части корректны.

## Ошибки и совместимость

Неполное значение не отправляется и не затирает сохранённое серверное
значение. При открытии существующего значения его числа показываются в трёх
сегментах; на выходе из редактора карточка использует уже существующий
канонический текстовый формат.

## Проверки

Перед реализацией будут добавлены тесты на:

1. единое визуальное поле с тремя сегментами и постоянными словами;
2. динамическое склонение;
3. переход `Пробелом` дни → месяцы → годы;
4. отсутствие действия `Пробела` в годах;
5. прежний структурированный payload и интеграцию в редакторы карточки.
