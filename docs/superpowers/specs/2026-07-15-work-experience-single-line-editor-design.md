# Однострочный ввод поля «Стаж работы»

**Дата:** 2026-07-15
**Статус:** согласовано пользователем; ожидает реализации

## Цель

Заменить текущий редактор из трёх отдельных полей «Дни», «Месяцы» и «Годы» на
одну строку ввода. Пользователь вводит три неотрицательных числа через пробел
в порядке `дни месяцы годы`, например `12 2 4`.

Пока поле находится в фокусе, числовой черновик остаётся редактируемым в том
виде, в котором его ввёл пользователь, например `12 2 4`. После потери фокуса
он автоматически заменяется нормализованным человекочитаемым значением
`12 дней 2 месяца 4 года`; склонения остаются динамическими. Отдельная кнопка
преобразования не нужна.

## Границы

- Это изменение только редактора React. Серверный контракт, `value_json` с
  технической опорной датой, пересчёт от даты сервера и экспорт не меняются.
- Поле остаётся одним schema-driven полем типа `work_experience`.
- Значение, отправляемое редактором, остаётся объектом `{ days, months, years }`;
  API не получает текстовую строку и не получает дату опоры.
- При незавершённом вводе (пустая строка, одно или два числа) редактор сохраняет
  введённый текст локально и не отправляет неполный объект до получения трёх
  чисел. Когда введены все три числа, редактор может отправить существующий
  объект `{ days, months, years }`, не заменяя числовой черновик до blur.
- Неподходящие символы и отрицательные числа не принимаются. Числа должны быть
  безопасными целыми JavaScript.

## Взаимодействие

1. Поле имеет один tab-stop и доступное имя карточного поля.
2. Пользователь вводит `дни месяцы годы` через один или несколько пробелов.
3. После третьего корректного числа редактор может вызвать существующий
   `onChange` с числовым объектом, но до потери фокуса оставляет в поле
   редактируемый числовой черновик.
4. При потере фокуса полный черновик автоматически заменяется канонической
   строкой `N дней N месяцев N лет` с актуальными окончаниями; кнопки
   преобразования нет. При повторном открытии или ответе сервера контрол также
   показывает эту каноническую строку.
5. `disabled` и подсказка продолжают работать как для обычного однострочного
   поля.

## Проверка

- Тест сначала фиксирует один `input`, один tab-stop и ввод `16 3 9`: пока
  поле в фокусе остаётся числовой черновик, при полной тройке может быть
  отправлен `{ days: 16, months: 3, years: 9 }`, а на blur он автоматически
  сменяется канонической русской строкой без кнопки преобразования.
- Отдельно проверяются неполный ввод, неверные символы, disabled-состояние,
  потеря фокуса и динамические склонения.
- Затем запускаются focused Vitest, TypeScript, ESLint и production build.
