# Глобальные брендовые изображения — дизайн

## Цель

Заменить условный знак приложения на предоставленный логотип и применить
предоставленное фоновое изображение на всех экранах Реестровой системы.

## Ресурсы

- `Логотип.png` становится единым растровым логотипом продукта.
- `Фон.png` становится единым глобальным фоном интерфейса.
- Оба файла копируются в отслеживаемую директорию исходников frontend с
латинскими именами, пригодными для URL сборщика. Исходные файлы пользователя
не изменяются.

## Отображение

- Фон применяется к `body` всех маршрутов, включая вход и публичные страницы.
- Он фиксирован относительно окна, не повторяется, выровнен по центру и
  масштабируется с `background-size: cover`, заполняя монитор без искажений.
- Поверх фона используется лёгкий светлый слой. Рабочее содержимое остаётся
  контрастным: панели имеют полупрозрачный светлый фон, достаточный для
  читаемости текста и форм.
- Логотип выводится через семантическое изображение с русским альтернативным
  текстом. Старый CSS-знак больше не рисуется.
- Замена охватывает экран входа, боковую панель и публичные страницы, где уже
  используется существующий блок бренда.

## Границы

- Название продукта, навигация, API, авторизация и данные не меняются.
- Не добавляются новые зависимости, миграции или настройки сервера.

## Проверка

- Проверить ссылки на оба ресурса и отсутствие старого CSS-логотипа в
  брендовых блоках.
- Запустить TypeScript, ESLint, Prettier и production-сборку frontend.
- Развернуть с помощью существующего frontend-скрипта и проверить HTTPS
  раздачу нового bundle и изображений.
