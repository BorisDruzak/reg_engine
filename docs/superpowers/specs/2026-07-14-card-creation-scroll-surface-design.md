# Создание карточки: закреплённая навигация и прозрачная рабочая область

## Цель

Убрать белое полотно внешней панели из экрана создания карточки, сохранив отдельные визуальные карточки базового блока и блоков шаблона. На широком экране навигация по блокам должна оставаться видимой при прокрутке и показывать текущий блок; на узком экране она остаётся обычным списком над полями.

## Выбранный вариант

1. Внешняя `data-panel`, содержащая только `single-stage-card-creation`, получает прозрачный фон и не рисует свою рамку. Поэтому за рабочей областью виден общий фон приложения.
2. Для этой же внешней панели отменяется `overflow: hidden`. Это устраняет ограничение, которое не даёт вложенному `position: sticky` следовать за прокруткой страницы.
3. Внутренние панели не меняются по назначению: базовый блок остаётся отдельной светлой карточкой, а каждый блок динамически выбранного шаблона — отдельной карточкой со своим состоянием заполнения.
4. На ширине больше мобильного breakpoint существующий `CardBlockNavigator` остаётся липким слева, ограничивается высотой окна и продолжает выделять блок, находящийся в области чтения. Клик по пункту по-прежнему плавно прокручивает к соответствующему блоку.
5. На ширине до `900px` существующее адаптивное правило сохраняется: навигатор становится обычным списком над полями и не закрепляется.

## Границы изменений

- Не меняются API, данные карточки, правило первого сохранения, статус черновика, динамическая загрузка шаблона и права доступа.
- Не меняются стили обычного просмотра карточки, публичного редактирования и остальных `data-panel`.
- Изменение ограничено стилями и регрессионной проверкой экрана создания карточки.

## Проверка

1. Компонентный тест фиксирует специальный прозрачный и `overflow: visible` контейнер только для экрана создания карточки.
2. Проверки TypeScript, ESLint и production-сборка фронтенда проходят без новых ошибок.
3. После публикации браузерная проверка на `https://regbase.sosnadmin.local/` подтверждает: общий фон виден вокруг внутренних карточек, навигатор виден после прокрутки, активный пункт меняется при переходе по блокам, а на мобильной ширине навигация остаётся над полями.
