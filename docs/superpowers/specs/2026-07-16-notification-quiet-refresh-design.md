# Тихое обновление уведомлений

## Цель

Сделать уведомления заметными без перезагрузки страницы и без влияния на
редактирование карточки.

## Размещение переключателя

Переключатель подписки на изменения карточки размещается в правой части шапки
`Базового блока`, рядом с названием и описанием блока. Он остаётся доступным
для любого пользователя, который может читать карточку, и не зависит от
загрузки представления карточки.

## Обновление колокольчика

Колокольчик опрашивает личный API уведомлений каждые 10 секунд. Это фоновый
запрос только для данных уведомлений: страница, выбранная карточка, поля
редактирования, локальные черновики и фокус ввода не перезагружаются и не
размонтируются.

Фоновое обновление не отображает индикатор загрузки и не запускается отдельно
при возврате фокуса окна. Оно обновляет только счётчик непрочитанных и
содержимое уже открытой панели уведомлений.

## Проверка

- тест размещения переключателя в шапке базового блока;
- тест десятисекундного интервала и отсутствия refetch при фокусе окна;
- тест, что поле карточки остаётся сфокусированным при обновлении уведомлений.
