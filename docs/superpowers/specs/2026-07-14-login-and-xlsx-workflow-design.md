# Логин пользователей и XLSX-обмен

## Цель

Убрать ложное требование e-mail при изменении логина пользователя и сделать
экран XLSX-обмена компактным и предсказуемым.

## Границы

- Существующее техническое поле и API-ключ `email` сохраняются для обратной
  совместимости, но в пользовательском интерфейсе и правилах валидации это
  логин.
- Логин обязателен, сравнивается без учёта регистра и может содержать буквы,
  цифры и специальные символы. Пробельные символы в логине не допускаются.
- Изменение не требует миграции: формат хранения пользователя не меняется.
- XLSX-обмен продолжает использовать один общий выбор шаблона, организаций и
  полей для экспорта и импорта.

## Логин

Сервис доступа заменяет e-mail-специфичную проверку на нормализацию логина:
обрезает пробелы по краям, приводит значение к нижнему регистру, отклоняет
пустые строки и любые пробельные символы. Проверка уникальности сохраняется.
Это позволяет сохранить действующие логины с `@`, а также использовать
логины вроде `upor`, `unit_123` и `admin-test`.

## XLSX-обмен

Если сервер возвращает ровно один доступный шаблон карточки, интерфейс
выбирает его автоматически. При первом выборе каждого шаблона все его
поддерживаемые поля включаются по умолчанию; пользователь может снять любой
выбор через общий выпадающий список с поиском и множественным выбором.

Экспорт и импорт располагаются в доступных вкладках `Экспорт` и `Импорт`.
Настройки XLSX остаются общими над вкладками. Вкладка экспорта показывает
только действие скачивания списка и его результат. Вкладка импорта показывает
скачивание шаблона, выбор файла, проверку, импорт и результаты. Это уменьшает
высоту экрана и не дублирует состояние настроек.

## Ошибки и тестирование

- Добавить backend-регрессии: логин без `@` и со специальными символами
  сохраняется; пробельный и совпадающий без учёта регистра логин отклоняется.
- Добавить frontend-регрессии: единственный шаблон выбран автоматически,
  поддерживаемые поля выбраны по умолчанию, список полей допускает поиск и
  снятие выбора, а вкладки показывают только активную операцию.
- Прогнать целевые тесты backend/frontend, TypeScript и production build;
  затем проверить сохранение логина и XLSX-экран в браузере на HTTPS-домене.
