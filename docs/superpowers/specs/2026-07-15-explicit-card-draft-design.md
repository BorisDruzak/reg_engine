# Явное сохранение черновика и единый базовый блок карточки

## Цель

Сделать экран создания эталоном для административной карточки и публичного
заполнения: один визуальный базовый блок, один навигатор и одинаковые блоки
полей. Карточка не должна возникать при открытии вкладки или при выборе
параметров; её создаёт только явное сохранение черновика.

## Создание карточки

- Поле `Организация карточки` всегда начинается пустым, даже если у
  пользователя доступна только одна организация.
- Если доступен один шаблон, он выбирается автоматически. При нескольких
  шаблонах пользователь выбирает один сам.
- Выбор организации, шаблона, наименования, переход по блокам и ввод в
  заблокированные поля не создают карточку и не меняют серверные данные.
- До выбора организации и шаблона кнопка `Сохранить черновик` неактивна.
- Явное нажатие `Сохранить черновик` создаёт карточку со статусом `Черновик`.
  Создание атомарно: сбой не оставляет карточку, значения или настройки
  публичного доступа.
- До сохранения черновика поля шаблона отображаются, но недоступны для
  редактирования; рядом есть понятная подсказка о необходимости сначала
  сохранить черновик.
- После сохранения базовые поля `Организация`, `Шаблон` и `Наименование`
  блокируются. Поля шаблона становятся редактируемыми. Статус автоматически
  меняется с `Черновик` на `Активно`, когда заполнены все обязательные поля.

## Навигация и действия

- Навигатор `Блоки карточки` остаётся отдельным закреплённым списком.
- Рядом с ним закрепляется отдельная область действий: до создания — кнопка
  `Сохранить черновик`, после создания — метка текущего статуса `Черновик` или
  `Активно`.
- В области действий до создания выводится подсказка, что поля будут
  редактируемыми только после сохранения черновика.

## Базовый блок и публичный доступ

- Базовый блок создания становится единым визуальным компонентом для создания,
  административного просмотра карточки и публичной формы.
- В административной существующей карточке организация, шаблон и наименование
  показаны теми же строками, но после сохранения не редактируются.
- `Публичный доступ` по умолчанию свёрнут. В административном режиме его можно
  раскрыть и изменить; до сохранения черновика он остаётся частью локального
  состояния и сохраняется вместе с черновиком.
- `Создать публичную ссылку` доступна только для уже сохранённой карточки.

## Публичное заполнение

- Публичная форма использует тот же базовый блок и оформление блоков полей.
- Организация, шаблон, наименование и настройки публичного доступа показываются
  только как сведения: никаких выпадающих списков, полей ввода или действий по
  их изменению.
- Публичный API принимает только значения полей, разрешённых ссылкой; попытка
  передать метаданные карточки или настройки доступа отклоняется.
- Навигация и статус отображаются безопасно, без административных действий,
  вложений и архивирования.

## Проверка

- Компонентные тесты: отсутствие автоматического создания, неактивная кнопка
  без пары организация/шаблон, блокировка полей до черновика, атомарное
  сохранение, смена статуса и недоступность публичной ссылки до черновика.
- API-тесты: явная команда создания черновика, откат при сбое и запрет публичной
  записи метаданных.
- Браузерная проверка: создание, административная карточка и публичная ссылка
  используют одинаковый базовый блок; публичные метаданные только для чтения.
