# Создание карточки: базовый блок и навигация по шаблону

## Цель

Вернуть для одноэтапного создания карточки понятную структуру обычной карточки:
с отдельным базовым блоком, навигацией по блокам шаблона и явным состоянием
заполнения. При этом карточка по-прежнему не создаётся до первого
непустого значения поля.

## Выбранный вариант

1. `Базовый блок` остаётся отдельной статичной панелью над рабочей областью.
   В ней находятся только организация, шаблон карточки, необязательное
   наименование и отмена создания.
2. После выбора организации и шаблона ниже открывается двухколоночная область,
   повторяющая обычный просмотр карточки: слева `Блоки карточки`, справа — все
   блоки шаблона в их обычном порядке.
3. Навигатор показывает название блока и состояние: не заполнен,
   требуется заполнение, заполнен либо нет полей. Нажатие переключает видимый
   участок правой колонки плавной прокруткой без перезагрузки страницы.
4. При прокрутке правой колонки текущий блок подсвечивается в навигаторе.
   После первого сохранения пользователь переходит в обычную карточку, как и
   сейчас.
5. На широком экране навигатор липкий: он остаётся видимым при прокрутке
   содержимого и ограничен высотой окна. На узком экране липкость отключается,
   а список остаётся над выбранным блоком.

## Визуальное решение

- Базовый блок получает собственную спокойную карточку с заголовком и
  пояснением, не смешиваясь с шаблонными полями.
- Шаблонные блоки показываются в рабочей части справа отдельными карточками с
  самостоятельными заголовками и промежутками; длинная страница остаётся
  управляемой через закреплённый навигатор.
- Рабочая область и базовый блок получают единый комфортный внутренний отступ,
  ограниченную ширину и промежутки между панелями. Контент не прижимается к
  границам главной области.
- Блоки и поля используют существующую палитру карточек: нейтральный фон для
  пустых, янтарное выделение для блоков с обязательными незаполненными полями,
  зелёное — для полностью заполненных. Само поле сохраняет заметную рамку,
  читаемую подпись и фокус без визуального шума.
- На узком экране навигатор становится обычной сеткой кнопок над выбранным
  блоком, как в существующем адаптивном виде карточки.
- Липкая навигация не выходит за рабочую область и прокручивает только свой
  список при большом числе блоков.

## Границы изменений

- Не меняются API, модель черновика, правила первого сохранения, права доступа
  и динамическая загрузка шаблона.
- Не изменяются обычный просмотр заполненной карточки и публичное
  редактирование; переиспользуются их компоненты и визуальные соглашения.
- Файловые поля остаются недоступными до создания карточки.

## Проверка

1. Компонентный тест: после выбора шаблона видны базовый блок, закреплённый
   навигатор и все разделённые блоки шаблона.
2. Компонентный тест: кнопка навигатора вызывает переход к нужному блоку и
   корректно показывает его статус.
3. Проверка TypeScript, тестов компонента и production-сборки фронтенда.
4. После публикации — браузерная проверка без создания тестовой карточки.
