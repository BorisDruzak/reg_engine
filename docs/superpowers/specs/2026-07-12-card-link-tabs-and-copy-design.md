# Карточки: постоянные вкладки и копирование ссылок

## Цель

Убрать перекрывающее поиск меню создания карточек и сделать получение ссылки
понятным одним нажатием.

## Согласованный дизайн

- Верхняя полоса `Вкладки карточек` всегда содержит после `Список карточек`
  три действия: `Создать карточку`, `Создать ссылку`, `Список ссылок`.
- Эти три вкладки не закрываются и не сохраняются в локальном хранилище как
  открытые карточки. Нажатие активирует соответствующую поверхность; список
  карточек и теговый поиск при этом не рендерятся под формой.
- Старое выпадающее меню и его кнопка из панели списка удаляются полностью.
- Нажатие на поле с URL в списке ссылок копирует весь URL в буфер обмена,
  выделяет его и показывает локальное сообщение `Ссылка скопирована`.
- Заголовок публичной карточки содержит кнопку `Копировать ссылку`, которая
  копирует текущий URL публичной карточки и подтверждает действие рядом с
  кнопкой. Срок действия остаётся отдельной информационной меткой.

## Ограничения

- Не менять серверные контракты, токены, срок действия или правила доступа.
- Использовать существующий браузерный Clipboard API и русский текст.
- Сохранить доступность: у интерактивного поля и кнопки должны быть понятные
  accessible names, а копирование должно быть проверяемо в Vitest.
