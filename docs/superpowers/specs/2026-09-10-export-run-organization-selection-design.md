# Выбор организаций при запуске XLSX-выгрузки

## Цель

Перенести запуск сохранённой XLSX-выгрузки из вкладки `Шаблоны выгрузки` во
вкладку `Экспорт карточек`. Шаблон хранит только структуру XLSX; организации и
период определяются при каждом запуске выгрузки.

## Пользовательский поток

### Шаблоны выгрузки

Вкладка предназначена только для управления шаблонами:

- создание и изменение названия, вида выгрузки, шаблона карточки и состава
  полей;
- архивирование;
- отсутствие выбора организаций, периода и кнопки `Скачать XLSX`.

### Экспорт карточек

Вкладка запускает сохранённую выгрузку в следующем порядке:

1. Пользователь выбирает вид: `Список карточек` или `Кадровые изменения`.
2. Список шаблонов содержит только шаблоны выбранного вида.
3. Пользователь выбирает шаблон и одну или несколько доступных организаций;
   кнопка `Все организации` выбирает все доступные организации.
4. Для `Кадровых изменений` пользователь вводит включительные дату начала и
   дату окончания периода.
5. `Скачать XLSX` отправляет выбранные организации и, при необходимости,
   период. Для обычной выгрузки создаётся единый лист без колонки организации;
   для кадровых изменений создаётся отдельный лист на каждую организацию.

## Контракт API и совместимость

- Конфигурация экспортного шаблона больше не содержит `organization_ids`.
- Запрос скачивания требует непустой список `organization_ids`; сервер на
  каждом запуске проверяет права пользователя на каждую организацию.
- Сохранённые шаблоны со старым `organization_ids` остаются читаемыми и
  скачиваемыми через новый экран, но старый список не используется. При первом
  сохранении такого шаблона ключ удаляется из JSON-конфигурации.
- Изменение использует существующее JSON-поле конфигурации, поэтому миграция
  схемы и изменение существующих карточек не требуются.

## Границы и качество

- Бизнес-поля остаются динамическими, определёнными схемой карточки.
- Сервер остаётся единственной границей авторизации и построения XLSX.
- Пользовательский текст остаётся русскоязычным.
- Тесты покрывают: отсутствие организаций в создаваемом шаблоне, фильтрацию
  шаблонов по виду, передачу выбранных организаций в download API, период для
  кадрового отчёта, игнорирование legacy-организаций и RBAC при скачивании.
